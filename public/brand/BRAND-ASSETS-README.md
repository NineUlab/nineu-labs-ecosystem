# Official NineU Labs Brand Assets

This directory contains the official NineU Labs logo and brand mark assets. Do not recreate, redraw, approximate, or generate these assets from code.

## Assets

### logo-wide-official.png
- **Purpose:** Primary brand logo for website headers, desktop navigation, Partner Program pages, and dashboards
- **Usage:** Horizontal layouts with sufficient width (1200px+ recommended)
- **Placement:** Website header, Partner Program introduction, dashboard branding

### logo-square-official.png
- **Purpose:** Square brand mark for mobile, login/splash screens, profile areas, and icon contexts
- **Usage:** Square layouts, app icons, favicon contexts
- **Placement:** App home screens, mobile headers, profile pictures, social media

### logo-nu-monogram-official.png
- **Purpose:** Compact NU monogram for mobile navigation, app icons, favicons, and small spaces
- **Usage:** Compact/icon sizes, mobile menu toggles, favicon
- **Placement:** Mobile navigation, favicon, compact headers, app shortcuts

## Rules

- Do not modify, redesign, or recreate these assets
- Use exactly as provided across all NineU Labs products
- Maintain consistent branding across public website, Partner Program, Partner Dashboard, Admin Dashboard, NineU Lead, and future products
- These assets are the single source of truth for the NineU Labs brand identity

## Application References

The application imports and uses these assets from `public/brand/` location:
- Website header components reference logo-wide-official.png
- Mobile views reference logo-nu-monogram-official.png
- Profile/icon contexts reference logo-square-official.png

All references are centralized in one location for consistency across the ecosystem.
