# NineU Labs Brand System

## Scope
This design system document is based on the official NineU Labs brand direction provided in the project brief and asset references. It is intended to guide the public site, partner platform, and future NineU Labs products without inventing a new independent brand.

## Core brand direction
- Premium
- Futuristic
- Intelligent
- Professional
- Enterprise-ready
- Modern SaaS
- Clean
- Trustworthy
- International

## Color system
The brand uses a dark navy base with high-contrast cyan and blue accents.

```css
--brand-navy-950: #020b1c;
--brand-navy-900: #071d3a;
--brand-blue-700: #0f5cc7;
--brand-cyan: #35e2ff;
--brand-blue: #1f5fff;
--brand-white: #eef7ff;
```

## Typography direction
- Large, high-contrast display type
- Tight tracking for product-style wordmarks
- Clean sans-serif forms
- Strong uppercase secondary headlines for technology messaging

## Layout principles
- Dark backgrounds with soft blue light glows
- Strong separation between content blocks
- Premium card surfaces with subtle border glow
- Responsive design for mobile-first implementation

## Image and logo usage requirement
The official NineU Labs logo assets were supplied as image references in the project brief. This repository will not recreate or replace them with invented logo variations. UI work in this stage uses the approved brand name treatment and color system while deferring exact asset placement until the official logo files are available in the project assets folder.

## Future implementation rule
Every future NineU Labs product and partner screen must remain visibly connected to the master NineU Labs brand system, while preserving a distinct product identity where needed.
